# Project Overview

## Objective

Build a portfolio-grade Issue/Complaint Management process for ServiceNow GRC.

The project connects complaints/findings with governance objects such as Policies, Risks and Controls and follows the issue through RCA, remediation, evidence, validation and closure.

## Scope

- Issue creation
- Triage
- Risk assessment
- Policy/Risk/Control mapping
- RCA
- Remediation
- Evidence
- Validation
- Closure
- Reporting

## Success Criteria

- Every issue has an owner.
- High-risk issues have risk-owner review.
- Remediation is tracked to a due date.
- Evidence is required before completion.
- Closure requires successful validation.
- Complete audit trail is maintained.
